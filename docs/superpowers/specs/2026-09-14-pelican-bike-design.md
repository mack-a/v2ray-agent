# 骑自行车的鹈鹕 SVG 动画设计

## 目标
创建一个无需依赖、双击即可打开的 HTML 页面，用 SVG 动画表现一只鹈鹕骑自行车，整体采用复古海报风格。

## 视觉
米黄色纸张背景，深蓝色线稿，橙红与珊瑚色作为主体和装饰色。页面包含标题、太阳、远山、草地与道路，主体居中并有足够留白。

## 动画
自行车两个车轮持续旋转；鹈鹕的双腿交替踩踏；身体和头部轻微上下起伏；云朵缓慢漂移。提供暂停/继续按钮，并尊重 `prefers-reduced-motion`。

## 技术
单文件 `pelican-bike.html`，原生 HTML/CSS/内联 SVG，无外部资源。通过 SVG `<animateTransform>`、CSS keyframes 和按钮事件控制动画状态。窄屏下缩放 SVG 与文本布局。

## 验收
打开文件即可看到完整构图和连续动画；按钮可暂停和恢复；页面在窄屏下不横向溢出。
